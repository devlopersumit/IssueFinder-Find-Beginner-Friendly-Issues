# IssueFinder

**Find fresh issues that match your skills. Land your first PR faster.**

IssueFinder helps you discover open, unassigned GitHub issues from projects that are still maintained — filtered by language, difficulty, and category.

**Live:** [issuefinder.fun](https://issuefinder.fun)

## What it does

- Browse fresh issues (updated recently, healthy repos)
- Filter by language, difficulty, category, and activity
- Explore repositories and categories
- Follow a short beginner guide to your first PR
- Dark / light theme

No AI. No noise. Search → filter → open on GitHub.

## Stack

- React + TypeScript + Vite
- Tailwind CSS
- GitHub REST API (public data)

## Setup

```bash
git clone https://github.com/sumitjhacodes/IssueFinder-Find-Beginner-Friendly-Issues.git
cd IssueHub/client
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

### Production build

```bash
cd client
npm run build
```

Output is in `client/dist`.
